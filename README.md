# Evolution 

A small evolution project featuring sharks and fish – created in TurboWarp/Scratch.

## Opening the project

You can download the HTML file or open the `.sb3` file in [TurboWarp](https://turbowarp.org/):
1. Download the file with the `.sb3` extension.
2. Then open [TurboWarp](https://turbowarp.org/).
3. Go to **File → Load from your computer** and select the `.sb3` file.

## How to use in TurboWarp

- Click on the **green flag** to start the simulation.
- Observe which sharks and fish adapt best and prevail.
- You can move using the **arrow keys** or **WASD**. If you press the **space bar**, you’ll be reset to the starting position. If you press 1, you’ll follow the fish until you press 1 again. To follow the shark, you can do the same with 2.
- You can end the simulation using the **red button**.

The HTML file starts when it is opened and ends when it is closed.

## What happens in the project?

The animals evolve over time.  
Your current data is automatically saved in the browser’s storage, so that it is retained.
